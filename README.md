# Курсова работа: Контейнеризация на проект "Книга за гости"

Този проект демонстрира пълна контейнеризация на уеб приложение ("Книга за гости"), реализирано на PHP, което комуникира с MySQL база данни за съхранение на потребителските съобщения. Цялата среда е конфигурирана и се управлява автоматично чрез **Docker** и **Docker Compose**.

---

## Структура на проекта

Проектът е организиран в следния вид:
* `src/` — съдържа сорс кода на PHP приложението (`index.php`, `db.php`).
* `style/` — съдържа стиловите CSS файлове за уеб интерфейса.
* `Dockerfile` — инструкции за изграждане на персонализирания уеб сървър.
* `compose.yml` — дефиниция и мрежова свързаност на контейнерите.
* `cursova.sql` — базов SQL скрипт за инициализация на базата данни.

---

## Архитектура и компоненти

Проектът се състои от две основни услуги, работещи в изолирана среда:

### 1. Уеб сървър (`web`)
* **Базов образ:** `php:8.2-apache`
* **Фини настройки (Dockerfile):** Инсталирани са разширенията `pdo` и `pdo_mysql`, необходими за връзката с базата данни.
* **Порт:** Конфигуриран е да слуша на стандартния порт `80` (мапнат като `80:80`).
* **Качен образ:** Персонализираният образ е публично достъпен в Docker Hub: [petark20/cursova-web](https://hub.docker.com/r/petark20/cursova-web)

### 2. База данни (`db`)
* **Базов образ:** `mysql:8.0`
* **Персонализация:** Използва се изолиран Docker обем (`mysql_linux_data`), за да се гарантира персистентност (запазване) на данните, дори след спиране или изтриване на контейнерите.

---

## Мрежова комуникация между услугите

Услугите комуникират помежду си чрез автоматично създадената вътрешна мрежа от Docker Compose. 

Във файла `src/db.php`, вместо стандартния хост `localhost`, за връзка е посочено името на Docker услугата:
```php
$host = "db";
```
Docker автоматично разпознава това име и пренасочва уеб трафика от PHP контейнера към MySQL контейнера.

---

## Инструкции за стартиране

За да изградите и стартирате проекта локално на вашия компютър, следвайте тези стъпки:

1. Свалете проекта и отворете терминала в неговата директория.
2. Стартирайте контейнерите на заден план (Detached mode) чрез Docker Compose:
   ```bash
   docker compose up -d
   ```
3. Ако стартирате средата за първи път, импортирайте базата данни от локалния `cursova.sql` файл в Docker контейнера със следната команда:
   ```bash
   docker exec -i cursova-db-1 mysql -u root -p123456 cursova < cursova.sql
   ```
4. Отворете вашия браузър и достъпете приложението на адрес:
   ```text
   http://localhost/src/index.php
   ```

---

## Спиране на средата

Когато приключите работа и искате да освободите системни ресурси, можете да спрете и премахнете контейнерите с командата:
```bash
docker compose down
```
*Забележка: Благодарение на конфигурирания Docker Volume, въведените съобщения в книгата за гости ще се запазят непокътнати при следващото стартиране.*
