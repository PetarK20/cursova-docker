# Курсова работа: Контейнеризация на проект "Книга за гости"

Този проект демонстрира пълна контейнеризация на уеб приложение ("Книга за гости"), реализирано на PHP, което комуникира с MySQL база данни за съхранение на потребителските съобщения. Цялата среда е конфигурирана и се управлява автоматично чрез **Docker** и **Docker Compose**.

---

## Структура на проекта

Проектът е организиран в следния вид:
* `src/` — съдържа сорс кода на PHP приложението (`index.php`, `db.php`).
* `style/` — съдържа стиловите CSS файлове за уеб интерфейса.
* `Dockerfile` — инструкции за изграждане на персонализирания уеб сървър.
* `compose.yml` — дефиниция и мрежова свързаност на контейнерите.
* `cursova.sql` — базов SQL скрипт за инициализация на базата данни.

---

## Архитектура и компоненти

Проектът се състои от две основни услуги, работещие в изолирана среда:

### 1. Уеб сървър (`web`)
* **Базов образ:** `php:8.2-apache`
* **Фини настройки (Dockerfile):** Инсталирани са разширенията `pdo` и `pdo_mysql`, необходими за връзката с базата данни.
* **Порт:** Конфигуриран е да слуша на стандартния порт `80` (мапнат като `80:80`).
* **Качен образ:** Персонализираният образ е публично достъпен в Docker Hub под името `petark20/cursova-web`.

### 2. База данни (`db`)
* **Базов образ:** `mysql:8.0`
* **Персонализация:** Използва се изолиран Docker обем (`mysql_linux_data`), за да се гарантира персистентност (запазване) на данните, дори след спиране или изтриване на контейнерите.

---
