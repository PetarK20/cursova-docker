# Курсова работа: Контейнеризация на Книга за гости (PHP & MySQL)

Този проект демонстрира пълна контейнеризация на PHP уеб приложение ("Книга за гости"), което комуникира с изолирана MySQL база данни чрез Docker Compose.

## Структура на проекта
- `src/` - Съдържа сорс кода на приложението (`index.php` и `db.php`).
- `style/` - Съдържа CSS стиловете за интерфейса (`style.css`).
- `mysql_data/` - Папка на хоста за персистентно съхранение на данните от базата.
- `init.sql` - SQL скрипт за автоматично създаване на таблицата `messages`.
- `Dockerfile` - Инструкции за изграждане на PHP-Apache контейнера с поддръжка на PDO.
- `compose.yml` - Конфигурационен файл за управление и стартиране на двете услуги заедно.

## Как работи всеки компонент?
1. **Услуга `db` (MySQL)**: Използва официален образ на MySQL 8.0. При първо стартиране чете файла `init.sql` и изгражда нужната таблица в базата данни `cursova`.
2. **Услуга `web` (PHP/Apache)**: Използва наш собствен `Dockerfile`, базиран на PHP с Apache. Добавено е разширението `pdo_mysql`, за да може приложението да прави сигурни заявки към базата.
3. **Комуникация**: Двата контейнера споделят обща мрежа. В `db.php` връзката е настроена да търси хост с име `db` (името на MySQL услугата), осигурявайки перфектна изолация от хост машината.
